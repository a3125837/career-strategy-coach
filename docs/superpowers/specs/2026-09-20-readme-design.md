# 职业战略教练 README 设计

## 目标

在仓库根目录新增 `README.md`，让第一次访问 GitHub 仓库的中文读者无需阅读 Skill 源文件，即可理解项目用途、正确调用方式、职业档案工作流、安全边界和验证状态。

## 主要读者

- 想使用职业战略教练分析职业路径、转岗、跳槽或职业规划的人。
- 想在 Codex 项目中使用或维护本 Skill 的开发者。

## 内容结构

README 按用户完成任务的顺序组织：

1. 项目定位与适用场景。
2. 核心能力。
3. 快速开始与调用示例。
4. 项目级文本别名 `/ZhiYeJiaoLian` 的真实边界。
5. 创建个人职业档案的提案、确认、初始化和校验流程。
6. `propose`、`init`、`validate` 命令示例。
7. 仓库目录结构。
8. 隐私和存储规则。
9. 测试结果与平台限制。
10. 许可证现状。

## 关键表述

- `/ZhiYeJiaoLian` 是本仓库 `AGENTS.md` 定义的项目级文本别名，不得写成 Codex 原生自定义斜杠命令。
- 也可以通过“帮我分析一下职业路径”等自然语言触发 Skill。
- Skill 不保存个人信息；个人职业信息只保存在用户确认的独立职业档案目录。
- 默认档案根目录为 `F:\AIPro\Career Strategy Coach  职业战略教练\career-profiles`，但默认路径不代表写入授权。
- 合法名称必须先交给只读 `propose`，展示绝对路径和恰好五项内容；用户明确确认后才能执行 `init`。
- `career-profiles/` 被 Git 忽略。
- 测试状态写为 33 项通过、4 项因当前 Windows 符号链接权限不可用而跳过；不得把跳过写成失败或完整覆盖。
- 仓库目前没有许可证文件，README 只陈述事实，不推断授权条款。

## 风格

- 以中文为主，命令、路径和文件名保持原样。
- 用户导向、可扫描、避免营销性空话。
- 不使用徽章、截图、复杂图表或未经验证的兼容性声明。
- 命令示例只展示当前仓库已实现和测试过的行为。

## 验收标准

- 根目录只有一份 `README.md`，Markdown 结构清晰且无占位符。
- 新读者能从 README 正确回答：项目做什么、如何调用、如何创建档案、何时写盘、个人信息存在哪里。
- README 中的路径、命令、五项档案结构、测试数量和非原生别名说明与仓库实现一致。
- 独立读者检查不发现关键歧义、错误假设或内部矛盾。
- README 提交后，本地 `master` 保持干净，并将同一提交同步到公开 GitHub 仓库。
